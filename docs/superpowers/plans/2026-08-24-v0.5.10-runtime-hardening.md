# Company Intelligence Engine V0.5.10 Runtime Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make v0.5.9 faster, cheaper, safer and easier to evolve without changing intelligence/scoring semantics, then leave a clean foundation for the V0.6 Decision Cockpit.

**Architecture:** Keep the existing provider → normalization → facts → events/signals → scoring pipeline, but introduce explicit execution intents and provider-capability health so routes no longer invoke exhaustive analysis unnecessarily. Co-locate Vercel compute with Neon, remove artificial UX latency, move optional UI work off the critical path, reduce SQL round trips, and harden scheduled monitoring.

**Tech Stack:** Next.js 16.3, React 19.2, TypeScript 6, Node 24, Vitest 4, Neon PostgreSQL 18, Managed Neon Auth, Vercel.

**Spec:** `docs/superpowers/specs/2026-08-24-v0.5.10-runtime-hardening-design.md`

## Global Constraints

- Preserve `FACT != INFERENCE`.
- Preserve RNE commercial-reuse fail-closed semantics.
- Preserve current v0.5 scoring outputs and `intelligence-v0.5.0` score version.
- Keep contacts authenticated, on-demand and `private, no-store`.
- Keep preview deployments read-only for production state.
- No speculative database index without EXPLAIN evidence.
- No Decision Cockpit UI in this release.
- Every behavior change follows TDD red → green → refactor.
- Full completion requires `npm run verify` and post-deploy evidence.
