# V0.5.3 — Decision Guardrails

V0.5.3 sépare explicitement deux notions qui ne doivent jamais être confondues :

- **Joignabilité** : présence web, emails publics, téléphones publics et gouvernance identifiable.
- **Autorisation d’action commerciale** : politique issue du statut `diffusionCommerciale` observé dans le RNE.

## Règles

- `allowed` : le scoring et les déclencheurs peuvent conduire à une qualification commerciale, sous réserve du RGPD et des conditions de réutilisation applicables.
- `blocked` : veille uniquement. Aucun trigger ne peut produire une recommandation commerciale immédiate et l’API Contacts refuse l’enrichissement.
- `unknown` : comportement fail-closed. Les signaux restent visibles, mais aucune prospection ni enrichissement de contacts n’est autorisé tant que le statut n’est pas confirmé.

La politique est retournée dans l’analyse via `commercialAction` afin que les interfaces et consommateurs API puissent appliquer le même garde de façon explicite.
