# V0.5.7 — Watchlist Navigation

La V0.5.7 rend enfin les watchlists réellement navigables dans le workspace, sans ajouter d’état persistant ni de migration.

## Navigation

La liste active est portée par l’URL :

`/workspace?watchlist=<uuid>`

Le workspace ne fait confiance qu’aux watchlists déjà chargées pour l’utilisateur authentifié. Un identifiant absent, invalide ou appartenant à un autre workspace est ignoré au profit de la première liste accessible.

## Expérience utilisateur

- Toutes les watchlists sont visibles sous forme de sélecteur en haut du workspace.
- La liste active est clairement mise en évidence.
- Chaque liste affiche le nombre d’entreprises actives qu’elle contient.
- La métrique principale devient « Dans la liste active » afin d’éviter toute ambiguïté.
- L’ajout d’un SIREN cible explicitement la liste sélectionnée.
- La création d’une nouvelle watchlist redirige immédiatement vers cette nouvelle liste.
- Les listes peuvent ainsi être organisées par marché, territoire, niveau de priorité ou toute autre logique métier.

## Sécurité

Les compteurs et le contenu des listes sont filtrés par appartenance au workspace directement en SQL. La sélection dans l’URL n’accorde aucun droit supplémentaire.

## Versioning

- Engine / application : `0.5.7`
- Modèle de score : reste `intelligence-v0.5.5`, car cette release ne modifie pas la formule de scoring.

Aucune migration Neon n’est nécessaire.
